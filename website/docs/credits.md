# Credits

## aventproxy

This app would not exist without [aventproxy](https://github.com/thekoma/aventproxy) by **thekoma**. aventproxy worked out how the Philips Avent monitors talk to the cloud and to your home network, and wrote it all down. This app builds on that work for everything Tuya-specific: signing in, the monitor's data points, the alarms per model, the lullaby tracks, the local connection and the live video.

If this app is useful to you, please give aventproxy a star on GitHub.
